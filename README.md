# 🎬 Base de Conhecimento - Clássicos dos Anos 80

> **Uma viagem nostálgica pelos filmes que definiram uma geração**

Aplicação web responsiva com estética **synthwave/cyberpunk** que cataloga e permite buscar filmes clássicos dos anos 80. Desenvolvida com HTML5, CSS3 e JavaScript vanilla, apresenta uma interface moderna inspirada no visual neon característico da década.

---

## ✨ Funcionalidades

- 🔍 **Busca Dinâmica**: Filtre filmes por nome ou descrição em tempo real
- 🎨 **Design Synthwave**: Paleta de cores neon com efeitos de glow
- 📱 **Totalmente Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- ⚡ **Carregamento Assíncrono**: Dados carregados via `fetch()` com tratamento de erros
- 🎯 **Navegação Intuitiva**: Interface limpa e fácil de usar
- 🔗 **Links Externos**: Acesso direto ao IMDb de cada filme

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Estilização moderna com variáveis CSS, gradientes e animações
- **JavaScript (ES6+)**: Lógica com `async/await`, `fetch API` e manipulação do DOM
- **Google Fonts**: Tipografia Quicksand

## 🚀 Como Usar

1. **Clone ou baixe os arquivos**
   ```bash
   git clone https://github.com/dougscodesontheloose/base-conhecimento-anos80.git
   ```

2. **Abra o arquivo `index.html` no navegador**
   - Não precisa de servidor local
   - Funciona diretamente no navegador

3. **Navegue e busque**
   - Digite no campo de busca: nome do filme, diretor ou palavras-chave
   - Pressione Enter ou clique no botão "Buscar"
   - Limpe a busca para ver todos os filmes novamente

## 🎯 Funcionalidades da Busca

A busca funciona de duas formas:
1. **Campo de input**: Digite e pressione Enter
2. **Botão**: Clique no botão "Buscar"

Busca por:
- Nome do filme
- Descrição/sinopse
- Não diferencia maiúsculas/minúsculas

---

## 📱 Responsividade

A aplicação se adapta a diferentes tamanhos de tela:

- **Desktop** (>768px): Layout em grid com 3-4 colunas
- **Tablet** (768px): Layout em grid com 2 colunas
- **Mobile** (<480px): Layout em coluna única
